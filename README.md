# 🐧 Linux Quest

An AI-powered Linux puzzle game designed to help developers improve their Linux command-line skills through interactive challenges.

## 🚀 About

Linux Quest turns Linux learning into a game.

Users choose a Linux category and solve AI-generated puzzles using Linux commands.

The game starts with simple challenges and gradually increases the difficulty as the player progresses.

## ✨ Features

- AI-generated Linux puzzles
- Interactive terminal-style gameplay
- Multiple Linux categories
- Easy → Medium → Hard progression
- Hints for difficult challenges
- Command validation
- XP and score system
- Developer-focused Linux learning
- Clean Apple-inspired interface
- Responsive frontend

## 📚 Categories

Current categories include:

- 📁 File Management
- 🔐 Permissions
- ⚙️ Processes
- 🌐 Networking
- 👥 Users & Groups
- 📜 Shell Scripting
